# 圆脸胶囊眼头像 · grok-bot-icon

根据人物照片制作圆脸、黑色胶囊眼、无嘴无鼻的 2D 插画头像。支持单人头像、情侣配套、人宠合影与局部精修。

本技能根据实际制作过程和确认的成图重写，包含默认单人构图、两张人宠成图参考，以及脸型、头颈倾斜、配套比例和局部编辑流程。

## 安装与使用

下载此仓库的完整 ZIP，或克隆仓库。将整个 `grok-bot-icon` 文件夹放入你的 Agent 支持的技能目录。Codex 可放在 `~/.codex/skills/grok-bot-icon`；已有安装时先备份，不要直接覆盖自己的修改。

向支持图像生成的 Agent 提供照片，例如：

> 使用 $grok-bot-icon，把这张照片做成头像。先查看技能中的视觉参考，再生成。

> 使用 $grok-bot-icon，为这两个人分别制作与各自宠物贴脸的配套头像。

参考图提供风格与构图，目标照片提供人物及宠物身份。生成需要 Agent 能查看图片，并将图片交给图像生成或编辑工具；本仓库本身不包含绘图模型。

## GitHub 完整版与 SkillHub 外链版

- **GitHub 完整版**随仓库附带三张参考图，读取参考图不需要额外下载。
- **SkillHub 外链版**不打包 PNG，安装后执行以下脚本补齐图片：

```sh
python3 /path/to/grok-bot-icon/scripts/fetch_references.py
```

脚本只从公开 GitHub 地址下载三张固定版本的参考图，按 SHA-256 校验；不上传照片，不需要 GitHub Token，也不会覆盖已有不同内容的图片。网络不可达时会报错，不能声称已查看参考图。也可从 GitHub 完整版复制 `references/` 中的图片。
