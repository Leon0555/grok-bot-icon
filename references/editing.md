# 配套匹配与局部编辑

## 先固定修改契约

开始编辑前，明确当前底稿、待变部分、保留部分和对照图。把它们直接写入绘图指令，无需每次向用户复述确认。

“人物可以了，小猫不对称”意味着锁住人物；“脖子短一点”意味着修改颈部与衣领衔接；“眼镜下边换成领边颜色”意味着只取现有领边的颜色改镜片下半圈细线。不要用全图重绘来顺带改变已通过的区域。

## 匹配头像时依次比较

1. **基准**：采用用户明确指定的那一张。同一轮不修改基准图。
2. **脸的尺度**：排除头发、耳朵和眼镜框，比较基础脸颊宽度、脸高、两眼距离及眼睛大小。被猫或头发遮住的部分需要按完整结构理解。
3. **脸的位置**：比较双眼中点与下巴在正方形画布上的相对位置。头发最高点和墨镜最高点不代表脸的位置。
4. **姿态**：比较双眼中心连线的斜率；胶囊长轴与它垂直。下巴居于自身脸轴上，颈部和衣领沿身体轴自然连接。
5. **可见颈长**：比较下巴到衣领沿颈部轴线的长度，以及它与脸高的比例。不要把阴影当作颈部边界；不要用拉长脸实现长脖子。
6. **宠物**：比较基础头脸大小、眼睛中点位置、人脸与宠物脸的大小关系。长毛轮廓可更大，但基础脸不能因此被过度缩小。

可以用眼睛中点、下巴、衣领三个锚点向绘图工具描述布局；必要时用相对画布位置辅助。避免凭目测给出精确像素要求并宣称精确匹配。

## 常见修改的实际含义

| 用户要求 | 应做的调整 | 需要保持 |
| --- | --- | --- |
| 再拉远一点 | 统一缩放人物内部各部件，补齐自然露出的颈部和衣领 | 脸眼比例与身份特征 |
| 脸大／小一点 | 围绕当前脸部中心轻微缩放头脸，眼睛、眼镜与头发协调变化 | 脸中心位置、倾斜、宠物 |
| 脖子长／短一点 | 沿现有颈轴轻移衣领，并重接颈部边界和阴影 | 头的位置、大小与脸型 |
| 脖子细一点 | 对称收窄颈部两边，自然接到下巴和衣领 | 颈长与头部 |
| 脸左右不对称 | 想象将头摆正后重建两侧对应的颊线与下巴，再一起旋转 | 发型本身的非对称设计 |
| 以某侧为准 | 按用户说明的画面方位保留该侧曲率，重建对应另一侧 | 头部中轴与脸中心 |
| 眼睛倾斜不对 | 对齐眼睛长轴、双眼连线与脸部中轴 | 眼睛形状与脸型 |
| 换情侣服 | 使用同一领口语言与配色，必要时先讨论选项 | 人物脸、发型、配饰、宠物 |

“一丢丢”“一点点”采用容易看出但克制的小步变化。先与上一版比较，不叠加多个大幅比例变化。AI 编辑可能不严格执行百分比，不能只凭提示词已写就判定成功。

## 看图后再交付

- 把底稿、结果、用户基准按相同画布尺寸比较，先查本轮修改，再查保留项。
- 人与宠物分开检查：各自是否正面、双眼等大、局部脸轴正确、双颊曲率相应、下巴居中。不要把不同主体的倾斜轴混在一起。
- 对脸颊不对称，判断来自头型、侧脸透视还是遮挡；针对原因修正，不重复笼统要求“更对称”。
- 对“没变化”或“越改越歪”，不要在每次未经认可的输出上继续累积修改，回到用户认可的版本。
- 每次只交付本轮需要修改的图片。生成两张、保存两张、交付两张是三件事，都要实际完成。
